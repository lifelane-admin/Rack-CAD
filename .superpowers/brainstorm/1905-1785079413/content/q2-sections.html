Rack Front View

The SVG rack canvas (one section per rack). The core visual — always included.

Rack Rear View

The rear panel showing PSUs, fans, and PCIe slots — side-by-side with front view.

3

Port Mapping Table

Every cable listed as a row: From Device / Port → To Device / Port, cable type, color.

4

Cable Legend

Color swatch + label for each cable type used (iDRAC, VM Network, Ceph, Power…).

5

Device Inventory Table

Per-rack list: Device, Model, RU position, Hostname, IP, Serial Number.

6

Design Notes

A free-text section you type inside the app — appears at the bottom of the document as deployment notes / change log.

7

Power Summary

Per-rack power draw vs. PDU capacity, weight totals, and any validation warnings.
