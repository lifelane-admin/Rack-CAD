Flexible Port Types — Data or Power, User's Choice

Any port on any device can be designated as Data or Power. Right-click a port to switch its type. No hardcoded "last port = PSU" rule.

Right-click a port → set type
Data behavior
• Renders as RJ45 jack (existing)
• Accepts Ethernet / fibre cables
• Switch LEDs blink when connected
• Default type for all ports
Power behavior
• Renders as IEC C14 inlet graphic
• Accepts power cables only
• On connect → asks plug sub-type
• C13 / C19 / IS6538 / NEMA / BS1363
• Cable auto-colored: red (A) or blue (B)
How cable type is detected automatically
When the user draws a cable between two endpoints, the app checks the port types at each end:
• data → data = network cable (existing behavior)
• power → pdu-outlet = power cable → prompts for plug sub-type (C13, IS6538…)
• power → data or data → pdu-outlet = blocked with tooltip "incompatible port types"
