============================================================
  RACK SLICER — Enterprise Datacenter Rack CAD Designer
============================================================

REQUIREMENTS
  - Windows 10 / 11
  - No installation required

------------------------------------------------------------
HOW TO START
------------------------------------------------------------

  Double-click  RUN_APP.bat

  The app will open automatically in your default browser at:
    http://localhost:8080

  Keep the console window open while using the app.
  Press Ctrl+C in the console to stop the server.

------------------------------------------------------------
macOS / Linux
------------------------------------------------------------

  Open a terminal in this folder and run:
    python3 -m http.server 8080

  Then open http://localhost:8080 in your browser.

------------------------------------------------------------
FEATURES
------------------------------------------------------------

  - Drag & drop rack layout design
  - Multi-vendor device library (Dell, HPE, Supermicro, etc.)
  - Cable routing with connector orientation control
  - Network legend editor
  - Lock, clone, and multi-select devices
  - Custom asset library (save your own device templates)
  - HTML design report export
  - SVG / PNG / JPG / PDF / JSON export
  - AI-assisted design (requires Anthropic API key)

------------------------------------------------------------
YOUR DESIGNS
------------------------------------------------------------

  Designs auto-save to your browser's local storage.
  Use File > Export JSON to save a portable backup file.
  Use File > Import JSON to restore a saved design.
